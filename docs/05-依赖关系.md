## 2. 模块间引用关系（`bud-web-master`）

```
main.tsx ──► App.tsx ──► pages/* ──► components/{Navbar, Footer, GreenButton, ...}
                  │
                  ├──► i18n.ts (i18next 初始化，被所有 useTranslation 使用)
                  ├──► components/RouteChangeTracker
                  ├──► components/Whatsapp
                  └──► util/ScrollToTop

pages/BUD.tsx ──► components/{RequiredDocuments, ApplicationGuide, GreenButton}
pages/Index.tsx / Audit.tsx / Subsidies.tsx / Listing.tsx ──► components/{Navbar, Footer, GreenButton}
```

引用方向统一为：**页面层 → 组件层 / 工具层**，组件之间无循环依赖。

## 3. 根级官网的模块依赖

单文件内依赖是**自上而下的函数作用域依赖**：数据常量 → 通用组件 → 页面组件 → `App`。无外部模块 import（除 `react`、`react-dom/client`、`styles.css`）。
