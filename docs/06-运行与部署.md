# 06 运行与部署

## 1. 环境要求

- Node.js 20 LTS 或更高版本
- npm（两个应用各自独立安装依赖）

## 2. 根级官网（`winfo-business-solutions`）

工作目录：仓库根目录。

```bash
npm install        # 安装依赖
npm run dev        # 启动开发服务器（默认 http://localhost:5173/）
npm run build      # 生产构建，输出到 dist/
npm run preview    # 预览生产构建
```

脚本定义见 [package.json](file:///Users/apple/Documents/ChatGPT/WinFo/package.json)。

### 构建特性

[vite.config.js](file:///Users/apple/Documents/ChatGPT/WinFo/vite.config.js) 内置一个自定义插件 `githubPagesFallback`：构建结束后将 `dist/index.html` 复制为 `dist/404.html`，用于 GitHub Pages 上 SPA 刷新时的回退。

## 3. `bud-web-master`（`WinFo-web`）

工作目录：[bud-web-master/](file:///Users/apple/Documents/ChatGPT/WinFo/bud-web-master)。

```bash
npm install
npm run dev       # vite 开发服务器
npm run build     # tsc -b && vite build（先类型检查再构建）
npm run lint      # eslint .
npm run preview   # 预览生产构建
```

另有 [start.sh](file:///Users/apple/Documents/ChatGPT/WinFo/bud-web-master/start.sh)：`nohup npm run dev --host 2>&1 &`，用于后台启动。

### 环境变量

| 变量 | 用途 |
| --- | --- |
| `VITE_GA_MEASUREMENT_ID` | GA4 测量 ID（`import.meta.env.VITE_GA_MEASUREMENT_ID`）。未设置时仅告警、埋点关闭 |

## 4. 部署（CI/CD）

[.github/workflows/build-and-deploy.yml](file:///Users/apple/Documents/ChatGPT/WinFo/.github/workflows/build-and-deploy.yml)：

1. 触发：push 到 `main` 分支或手动 `workflow_dispatch`。
2. Job `build`：`actions/checkout@v4` → `actions/setup-node@v4`（Node 20 + npm 缓存）→ `npm ci` → `npm run build` → 上传 `dist` 为 Pages artifact。
3. Job `deploy`：`actions/deploy-pages@v4` 发布到 GitHub Pages。

> 注意：该 workflow 位于仓库根，构建的是根级官网（读取根 `package.json`）。`bud-web-master` 不在其构建范围内。

## 5. 常见注意事项

- **表单尚未接入后端**：根级官网 `ContactPage` 与 `bud-web-master` 各页表单均为本地演示，未连接真实收件箱/接口。根级官网提交仅 `setTimeout` 模拟成功状态。
- **隐私/条款需法务复核**：根级官网 README 明确隐私政策需经公司法律顾问审阅后方可上线。
- **评价为示意草稿**：`testimonialCopy` 标注为 draft/illustrative，发布前需替换为已授权真实反馈。
- **端口占用**：若 5173 被占用，Vite 会自动改用下一个可用端口。
