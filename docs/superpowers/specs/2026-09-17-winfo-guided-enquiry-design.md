# WINFO 分步公司注册咨询流程设计规格

日期：2026-09-17

## 目标

把公司注册页面的首要行动改为清晰的双入口：

1. 「注册公司／開始公司註冊」直接进入独立分步表单
2. 「免费初步咨询」继续打开 WhatsApp 或顾问联系渠道

用户不需要滚动到页面底部寻找表单，也不需要一次填写一张很长的表格。流程参考 Sleek 的逐步决策体验，但使用 WINFO 自有品牌、文案、业务结构与视觉系统，不复制 Sleek 的页面、促销、报价或组件细节。

## 变更范围冻结

本轮只允许改动公司注册入口与分步填表流程。除完成以下必要连接外，网站其他部分全部冻结：

- 首页或公司注册相关首屏中的「开始公司注册」按钮跳转目标
- 公司注册服务页中原有长表单的位置与替代入口
- 价格页香港人士／内地人士公司注册方案的表单入口
- 新增 `/start/company-registration` 分步表单页面及其三语文案、样式、状态和提交逻辑

本轮不得改动：首页其他模块、其他服务页内容、现有价格、客户评价、评分展示、导航结构、页脚、品牌主色、字体系统、动画、Cookie、法律页面及其他既有功能。若实现过程中发现范围外问题，只记录，不顺带修改。

## 入口设计

### 首页及公司注册服务页

- 主按钮：`开始公司注册`／`Start company registration`
- 次按钮：`免费初步咨询`／`Free initial consultation`
- 主按钮跳转至 `/start/company-registration`
- 次按钮打开已有 WhatsApp 咨询链接
- 原有页面下方的完整注册表单移除，改为简短的流程说明及再次进入分步表单的按钮

### 价格页及导航

- 香港人士方案进入 `/start/company-registration?profile=local`
- 内地人士方案进入 `/start/company-registration?profile=mainland`
- 导航中的公司注册服务仍先进入服务介绍页，不强制所有访客直接进入表单

## 分步表单信息架构

桌面端使用专注式单页流程；移动端使用单栏流程。每一步只处理一个主题，并保留返回、继续及稍后决定能力。

### 第 1 步：公司名称

- 输入最多三个心仪公司名称
- 提示名称需经正式查册后才能确认
- 提供「稍后决定」选项

### 第 2 步：创办人情况

- 香港本地人士
- 内地人士
- 其他／尚未确定
- 董事及股东人数

### 第 3 步：业务基本资料

- 业务性质
- 预计开始时间
- 是否已有香港公司
- 不要求提交身份证、银行月结单或其他敏感文件

### 第 4 步：服务需要

- 是否需要注册地址及邮件代收
- 是否需要银行开户资料准备
- 是否需要后续记账、审计及报税咨询
- 这里只收集意向，不构成最终报价或服务承诺

### 第 5 步：联系方式

- 姓名
- 电话或电邮
- 补充说明
- 私隐政策同意

### 第 6 步：核对并提交

- 显示用户选择的咨询摘要
- 允许返回修改
- 明确说明提交后由 WINFO 审阅并联系用户
- 送出到现有 `/api/enquiry` 接口
- 成功后显示确认页，并保留 WhatsApp 即时联系入口

## 页面结构

### 顶部

- WINFO 蓝色 Logo
- 语言切换：英语、繁体中文、简体中文
- 退出并返回网站
- 横向进度条，显示当前步骤及总进度

### 主内容区

- 左侧／中央为当前步骤问题
- 问题标题短而明确
- 输入框、单选卡、下拉选择及说明文字沿用 WINFO 设计系统
- 主操作按钮使用 WINFO 蓝色

### 桌面摘要区

- 右侧显示「你的咨询摘要」
- 只显示已填写资料及已选择服务
- 不展示未经确认的折扣、政府收费总额、评分、退款保证或获批承诺

### 移动端

- 单栏布局
- 顶部显示 `步骤 X / 6`
- 摘要折叠为可展开区域
- 底部固定「继续」按钮，但不遮挡系统导航及 WhatsApp 入口

## 视觉语言

- 品牌主色：WINFO 蓝 `#3080FF`
- 标题：深蓝 `#173B72`
- 背景：白色及浅蓝 `#F7FBFF`
- 金色只用于少量提示与品牌细节
- 卡片圆角保持克制，以清晰边框和留白为主
- 不使用 Sleek 的橙色促销条、绿色价格卡、Google 评分陈列、客服头像框或侧边报价栏造型

## 数据与状态

- 表单状态由独立 `CompanyRegistrationWizard` 管理
- 步骤配置与翻译文案分离，便于三种语言维护
- 返回上一步时保留已填内容
- 页面刷新时使用 `sessionStorage` 暂存非敏感草稿
- 成功提交后清除草稿
- 不把身份证、银行文件或 API 密钥存入浏览器状态

## 校验与错误处理

- 每一步仅校验当前所需字段
- 公司名称允许跳过
- 联系方式与私隐同意必须完成
- 网络失败时保留草稿，显示重试、WhatsApp 与电邮备用入口
- 防止重复提交，并显示发送中状态
- 接口继续执行服务器端字段长度、来源与蜜罐校验

## 验收标准

1. 点击首屏「开始公司注册」可直接进入分步表单，不滚动到原页面底部
2. 点击「免费初步咨询」仍可打开 WhatsApp 咨询
3. 用户可前进、返回、稍后决定，并保持已填资料
4. 香港／内地身份入口可预选相应身份
5. 桌面与手机均可完成全部步骤，无横向溢出或关键按钮遮挡
6. 英语、繁体中文、简体中文文案完整
7. 提交成功、失败及未配置收件端点均有真实提示
8. 不出现未经核实的评分、案例、折扣、保证或审批承诺
9. `npm run build` 通过，并以浏览器实测完整流程

## 明确不包含

- 在线付款或结账
- 即时公司名称可用性保证
- 自动政府查册
- 文件上传
- 客户账户系统
- 未经确认的价格总计或优惠
