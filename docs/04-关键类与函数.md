### 1.1 路由

```js
function routeFor(pathname)      // string → { name: 'home'|'services'|'service'|...|'404', id? }
```
- 归一化尾部斜杠；`/` → `home`；`/services/:id` → `{ name:'service', id }`；未匹配 → `{ name:'404' }`。

```js
function useRoute()              // → [route, navigate]
```
- 内部 `useState` 保存当前路由，`useEffect` 监听 `popstate`，路由变化时滚动到顶部。
- `navigate(to)`：`pushState` 后调用 `routeFor` 更新状态；支持 `path#hash` 拆分。

### 1.5 根组件

```js
function App()                                      // 路由分发 + 语言 + document.title
createRoot(document.getElementById('root')).render(<App />)
```

`App` 内 `useEffect` 负责：持久化语言到 `winfo-language`、设置 `<html lang>`（en/zh-Hant/zh-Hans）、按路由设置 `document.title`。
