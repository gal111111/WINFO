# 01 项目概览

## 1. 仓库定位

WINFO 仓库是「盈丰商业有限公司」（WINFO Business Solutions Ltd.）的官方网站代码库。业务定位为香港跨境企业服务，覆盖公司成立、会计审计、BUD 资助、科技园落地（HKSTP）、内地创新园区补贴、上市维护等。

对标网站 **Sleek.com** 与 **Osome.com** 是公司注册/秘书/会计类 SaaS 的标杆，本仓库在信息架构与设计语言上参考其「价值 → 信任 → 服务 → 转化」的结构逻辑。

## 2. 仓库组成

仓库实际包含**两个相互独立的前端应用**与一份设计规范文档：

| 位置 | 应用名（package name） | 说明 | 状态 |
| --- | --- | --- | --- |
| `src/`（根级） | `winfo-business-solutions` | WINFO 全新企业官网 | 当前主站 |
| `bud-web-master/` | `WinFo-web` | BUD/资助/上市等多页面营销站 | 早期版本，仍保留 |
| `_backups/content-lab-before-company-site-20260904/` | Content Lab | 同行内容研究工具 | 历史备份 |

## 3. 技术栈总览

### 应用一：根级官网（`winfo-business-solutions`）

| 维度 | 选择 |
| --- | --- |
| 构建 | Vite |
| UI 框架 | React（最新版） |
| 语言 | JavaScript（JSX），**无 TypeScript** |
| 路由 | 自研 `useRoute` + History API，**无 react-router** |
| 国际化 | 自研字典对象（`copy` / `serviceContent` 等），无 i18n 库 |
| 样式 | 手写 CSS（`styles.css`），CSS 自定义属性做设计令牌 |
| 字体 | Google Fonts（Noto Sans TC + DM Sans） |

入口文件：[index.html](file:///Users/apple/Documents/ChatGPT/WinFo/index.html) → [src/main.jsx](file:///Users/apple/Documents/ChatGPT/WinFo/src/main.jsx)。

### 应用二：`bud-web-master`（`WinFo-web`）

| 维度 | 选择 |
| --- | --- |
| 构建 | Vite 6 |
| UI 框架 | React 19 |
| 语言 | TypeScript 5.7（strict 模式） |
| 路由 | react-router-dom 7 + react-router-hash-link |
| 国际化 | i18next + react-i18next + 浏览器语言探测 + HTTP backend |

入口文件：[bud-web-master/index.html](file:///Users/apple/Documents/ChatGPT/WinFo/bud-web-master/index.html) → [bud-web-master/src/main.tsx](file:///Users/apple/Documents/ChatGPT/WinFo/bud-web-master/src/main.tsx)。

## 4. 两个应用的关系

- **无代码层面的依赖**：两者是独立打包、独立 `node_modules`、独立 `package.json` 的应用，互不 import。
- **共享资源**：根级 `public/` 与 `bud-web-master/public/` 分别维护各自的静态图（`Main_banner.jpg`、`WINFO-*.png` 等）。
- **业务关系**：根级官网是面向「企业服务」的新门户；`bud-web-master` 是聚焦「资助/落地」细分业务的落地页集合。品牌规范（docx）是为根级官网建立的设计系统，`bud-web-master` 尚未迁移到该规范。
