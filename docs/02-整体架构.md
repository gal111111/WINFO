# 02 整体架构

## 1. 应用一：根级官网（`winfo-business-solutions`）

### 1.1 分层结构

这是一个**单文件应用**，所有逻辑集中在 [src/main.jsx](file:///Users/apple/Documents/ChatGPT/WinFo/src/main.jsx)（约 423 行），自上而下可分为四层：

```
┌─────────────────────────────────────────────┐
│  ① 数据层（顶层常量）                          │
│  languages / serviceItems / finderCopy        │
│  faqCopy / contactFormMeta / cookieCopy       │
│  legalCopy / finderOptions / testimonialCopy  │
│  copy（三语字典）/ serviceContent（服务详情）    │
├─────────────────────────────────────────────┤
│  ② 基础设施（通用组件 / Hooks）                 │
│  Icon / routeFor / useRoute / Reveal          │
│  ParticleField / PageShell / PageIntro        │
├─────────────────────────────────────────────┤
│  ③ 页面与区块组件                              │
│  Header / HomePage / ServicesPage / ServicePage│
│  PricingPage / CasesPage / ApproachPage        │
│  AboutPage / ContactPage / PrivacyPage         │
│  TermsPage / NotFoundPage / Footer             │
├─────────────────────────────────────────────┤
│  ④ 根组件与挂载                               │
│  App（路由分发 + 语言 + 标题）→ createRoot      │
└─────────────────────────────────────────────┘
```

### 1.2 路由机制（自研，非 react-router）

- [routeFor(pathname)](file:///Users/apple/Documents/ChatGPT/WinFo/src/main.jsx#L261-L274)：把路径字符串归一化为 `{ name, id? }` 路由对象。
- [useRoute()](file:///Users/apple/Documents/ChatGPT/WinFo/src/main.jsx#L276-L292)：用 `window.history.pushState` 做导航、监听 `popstate` 回退、路由变化时 `scrollTo(0,0)`。
- `App` 内部用 `if/else` 根据 `route.name` 选择渲染哪个页面组件。

### 1.3 数据流

1. `App` 维护 `route`（来自 `useRoute`）与 `lang`（来自 `useState` + localStorage）。
2. `t = useMemo(() => copy[lang] || copy.en, [lang])` 得到当前语言文案。
3. `t`、`lang`、`navigate` 通过 props 逐层下发给页面与区块组件。
4. 服务详情通过 `serviceContent[item.key][lang]` 二次查表。

## 2. 应用二：`bud-web-master`（`WinFo-web`）

### 2.1 分层结构

采用典型的 **React + react-router + i18next + Tailwind** 目录分层：

```
src/
├── main.tsx                 # 入口（StrictMode + App + i18n）
├── App.tsx                  # 路由表 + GA 初始化 + 全局挂件
├── i18n.ts                  # i18next 初始化 + 三语资源
├── App.css / index.css      # Tailwind 入口与工具类
├── pages/
│   ├── Main/MainPage.tsx    # 首页
│   ├── Index.tsx            # 银行/公司服务页
│   ├── BUD.tsx              # BUD 基金
│   ├── STP.tsx              # HKSTP 科技园
│   ├── Audit.tsx            # 审计服务
│   ├── Subsidies.tsx        # 内地创新园区补贴
│   └── Listing.tsx          # 上市维护
├── components/              # 可复用组件（见模块职责）
└── util/                    # ScrollToTop / constants
```

### 2.2 路由表

定义于 [App.tsx](file:///Users/apple/Documents/ChatGPT/WinFo/bud-web-master/src/App.tsx#L56-L68)：

| 路径 | 组件 |
| --- | --- |
| `/` | `MainPage` |
| `/index` | `IndexPage` |
| `/BUD` | `BUDPage` |
| `/stp` 与 `/STP` | `STPPage` |
| `/AuditServicesPage` | `AuditServicesPage` |
| `/Subsidies` | `InnovationSubsidiesPage` |
| `/listing` | `ListingPage` |

### 2.3 数据流

1. 全局挂件：`RouteChangeTracker`（GA 埋点）、`ScrollToTop`（切换路由回顶）、`ScrollToHashElement`（hash 锚点平滑滚动）都在 `Router` 内挂载。
2. `WhatsappButton` 作为全局悬浮按钮渲染在所有页面底部。
3. 文案通过 `useTranslation()` 的 `t()` 按 key 从 `i18n.ts` 读取，语言由 `LanguageDetector` 探测。

## 3. 两个应用架构对比

| 维度 | 根级官网 | bud-web-master |
| --- | --- | --- |
| 文件组织 | 单文件 | 分层多文件 |
| 路由 | 自研 Hook | react-router-dom 7 |
| 语言 | 手写字典 | i18next |
| 类型 | JS | TS strict |
| 样式 | 手写 CSS | Tailwind v4 |
| 复杂度 | 低，易读 | 高，模板重复较多 |
