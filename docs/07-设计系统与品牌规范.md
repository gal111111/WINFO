# 07 设计系统与品牌规范

> 来源：用户提供的《WINFO 網站設計品牌規範》（Letterhead.docx），为根级官网建立的设计系统。对标 **Sleek.com** 与 **Osome.com** 的「专业感」结构，转化为 WINFO 自有视觉语言（浅蓝 + 金色识别）。

## 1. 核心视觉方向

「可信、清晰、现代而有人情味」：白色建立专业与透明感，浅蓝承载资讯/流程/服务卡片，深蓝用于文字与主要行动，金色仅作高价值识别与细节点缀。

## 2. 色彩系统（已落地到 `styles.css`）

| 色彩 | HEX | 建议比例 | 用途 | 代码令牌 |
| --- | --- | --- | --- | --- |
| White 白 | `#FFFFFF` | 70% | 主背景、卡片、留白 | `background: #fff` |
| WINFO Light Blue | `#EAF4FF` | 20% | 区块背景、提示、流程面 | `--soft` |
| WINFO Blue | `#3080FF` | 8% | 主 CTA、链接、选中态 | `--blue` |
| Logo Gold | `#D2AD6C` | ≤2% | Logo、认证、关键细线/图标 | `--gold` |
| Deep Blue | `#173B72` | 文字 | 标题、导航、深色区块 | `--ink` |
| Ink / Muted | `#172033` / `#5B677A` | 文字 | 正文 / 次要说明 | 默认色 / `--muted` |

对应代码位置：[src/styles.css](file:///Users/apple/Documents/ChatGPT/WinFo/src/styles.css#L3) 的 `:root` 自定义属性：

```css
:root {
  --blue: #3080ff; --ink: #173b72; --muted: #5b677a;
  --line: #d6e7fb; --soft: #eaf4ff; --gold: #d2ad6c;
  --max: 1200px;
}
```

## 5. 首页信息架构（价值 → 信任 → 服务 → 转化）

| 次序 | 区块 | 目的 |
| --- | --- | --- |
| 01 | 导航 + Hero | 说清价值并导向行动（H1 + 副标 + 「免费咨询」主 CTA + 「查看方案」次 CTA） |
| 02 | 信任带 | 只用已核实资料（牌照、年资、客户数、评价、合作伙伴） |
| 03 | 服务 + 价格 | 按「成立公司 / 日常合规 / 会计审计」分卡，最多三档价格 |
| 04 | 三步流程 | 01 了解需求 → 02 准备提交 → 03 持续支援 |
| 05 | 案例 + FAQ + CTA | 可核实客户引言，6–8 个高频问题，最后连 WhatsApp/表单/预约 |
| 06 | 合规页脚 | 公司全名、地址、电邮、电话、牌照、隐私条款，深蓝底白字金色细节 |

> 该结构已体现在根级官网的 `HomePage` 各区块顺序中（hero → proof → services → finder → why → cases → testimonial → final CTA）。

## 6. 组件特征（Component Signatures）

| 组件 | 视觉规则 | 交互/内容规则 |
| --- | --- | --- |
| 按钮 | 主：Blue 底白字；次：白底 Blue 边；10px 圆角 | 动词开头；同区只设一个主行动；hover/focus 清晰 |
| 服务卡 | 白/Light Blue 面、16px 圆角、细边框；hover 上移 4px | 标题 + 一句价值 + 3 个要点 + 单一链接 |
| 价格卡 | 三栏上限；推荐卡用蓝顶边或 Gold 小标签 | 列总价、政府费用、续费、附加费；「由」价必须附条件 |
| 表单 | 每行一栏；label 永远可见；错误以文字 + 图标 | 只收必要资料；提交后列下一步及预计回复时间 |

## 7. 无障碍与内容守则

- 文字与背景对比度 ≥ 4.5:1
- 所有可点元素具备 hover、focus、disabled 状态
- 正文 ≥16px；图片需 alt；手机 CTA 触控区 ≥44×44px
- 中文避免中英标点混乱，金额统一使用 HK$

代码中已落地：`button:focus-visible` 焦点轮廓、`prefers-reduced-motion` 降级、`aria-*` 属性等（见 [styles.css](file:///Users/apple/Documents/ChatGPT/WinFo/src/styles.css#L11) 与 `Reveal`/`ParticleField` 的降级逻辑）。

## 8. 对标网站提取的设计原则

- **Sleek**：强首屏价值、双行动入口、信任/牌照证明、方案与三步流程。
- **Osome**：大量留白、按企业阶段分组服务、卡片式内容、「专家 + 科技」双主线。

WINFO 采用以上结构逻辑，但保留自身浅蓝与金色识别，不复制对方插图、文字或品牌资产。
