# 03 模块职责

## 1. 根级官网（`winfo-business-solutions`）

核心代码都在 [src/main.jsx](file:///Users/apple/Documents/ChatGPT/WinFo/src/main.jsx)，按职责分为「数据模块」与「组件模块」。

### 1.1 数据模块（顶层常量）

| 常量 | 职责 |
| --- | --- |
| `languages` | 语言切换器项（en / zh-TW / zh-CN） |
| `serviceItems` | 6 项服务的元数据（id、icon、key、group） |
| `serviceContent` | 每项服务在三种语言下的详情（name/summary/detail/items/process） |
| `copy` | 全站三语文案（导航、hero、各页面、隐私、404、页脚） |
| `finderCopy` | 「从哪里开始」引导器文案 |
| `faqCopy` | 定价页 / 服务页两套 FAQ 文案 |
| `contactFormMeta` | 表单提示（同意、提交中、本地预览说明） |
| `cookieCopy` | Cookie 提示文案 |
| `legalCopy` | 使用条款（terms）文案 |
| `testimonialCopy` | 客户评价（标记为草稿/示意） |
| `finderOptions` | 引导器选项到服务 id 的映射 |

### 1.2 基础设施组件

| 组件 | 职责 |
| --- | --- |
| `Icon` | 内联 SVG 图标库（arrow/chevron/menu/building/ledger 等） |
| `routeFor` / `useRoute` | 路径解析与 SPA 路由 Hook |
| `Reveal` | 基于 IntersectionObserver 的滚动入场动画，尊重 `prefers-reduced-motion` |
| `ParticleField` | Canvas 粒子动效（hero 背景） |
| `PageShell` | 页面统一 `<main>` 容器 |
| `PageIntro` | 页面顶部标题/副标题区块 |

### 1.3 页面与区块组件

| 组件 | 对应路由 | 职责 |
| --- | --- | --- |
| `Header` | 全局 | 导航 + 服务 mega 菜单 + 语言切换 + 移动菜单 |
| `ServiceMenuLink` | Header 内 | mega 菜单中的单项服务链接 |
| `HomePage` | `/` | 首页（hero、信任带、服务预览、引导器、方法、案例、评价、CTA） |
| `ServicesPage` | `/services` | 服务总览（IANG 重点服务 + 全服务网格） |
| `ServicePage` | `/services/:id` | 服务详情（概览、包含项、流程、FAQ、评价、CTA） |
| `PricingPage` | `/pricing` | 三档定价 + FAQ + 评价 |
| `CasesPage` | `/cases` | 案例列表 + 类型筛选 |
| `ApproachPage` | `/approach` | 四步方法论 |
| `AboutPage` | `/about` | 公司简介 + 数据 + 价值观 |
| `ContactPage` | `/contact` | 联系信息 + 表单（本地演示） |
| `PrivacyPage` | `/privacy` | 隐私政策 |
| `TermsPage` | `/terms` | 使用条款 |
| `NotFoundPage` | 404 | 兜底页面 |
| `Footer` | 全局 | 页脚导航 + 联系方式 |
| `CookieNotice` | 全局 | Cookie 提示（localStorage 记忆） |

区块组件 `ServiceCard`、`PageCta`、`TestimonialSection`、`ServiceFinder`、`FAQSection` 被多个页面复用。

## 2. `bud-web-master`（`WinFo-web`）

### 2.1 页面（`src/pages/`）

| 文件 | 默认导出 | 职责 |
| --- | --- | --- |
| `Main/MainPage.tsx` | `MainPage` | 首页：Hero/About/Projects（横向滚动卡片）/Contact |
| `Index.tsx` | `IndexPage` | 银行开户 / 公司账户服务页（标准/尊享方案对比 + 表单） |
| `BUD.tsx` | `BUDPage` | BUD 基金：资助详情、范围、地区、对比表、申请流程、所需文件 |
| `STP.tsx` | `STPPage` | HKSTP 科技园：四阶段计划卡片 + 详细对比表 + 申请时间线 |
| `Audit.tsx` | `AuditServicesPage` | 审计：年审、报税、强积金、增值服务 |
| `Subsidies.tsx` | `InnovationSubsidiesPage` | 内地创新园区补贴（学历补贴、港澳青年创业、梦工场等） |
| `Listing.tsx` | `ListingPage`（内部命名 `InnovationSubsidiesPage`） | 上市维护、上市前后融资、排除项 |

> 注：`Listing.tsx` 的默认导出函数名误写为 `InnovationSubsidiesPage`（与 `Subsidies.tsx` 重名），属复制粘贴遗留，不影响运行（`App.tsx` 用别名 `ListingPage` 导入）。

### 2.2 组件（`src/components/`）

| 组件 | 职责 |
| --- | --- |
| `Navbar` | 桌面/移动导航切换，含项目下拉菜单与语言切换 |
| `Footer` | 页脚导航 + 合作方 Logo 墙（`Collabortors`） |
| `GreenButton` | WhatsApp 绿色 CTA 按钮 |
| `Whatsapp`（`WhatsappButton`） | 全局悬浮 WhatsApp 按钮 |
| `RouteChangeTracker` | GA4 页面浏览埋点 |
| `Toaster` | 成功/失败消息提示（5 秒自动消失） |
| `ApplicationGuide` | BUD 申请方案选择对照表 |
| `RequiredDocuments` | BUD 申请所需文件三栏表格（桌面/移动） |
| `PriceListDesktop` / `PriceListMobile` | 服务价格清单（标准/尊享） |

### 2.3 工具（`src/util/`）

| 文件 | 职责 |
| --- | --- |
| `ScrollToTop.tsx` | 路由切换时回到页面顶部 |
| `constants.ts` | 首页项目卡片数据（`projects` 数组，引用 i18n key） |
